# E-commerce + LLM GitHub Report

This folder contains a printable PDF report generated by:

```
python3 scripts/ecom_llm_github_report.py \
  --max-repos 50 \
  --include-readme \
  --include-code \
  --download-font \
  --output reports/ecommerce_llm_report.pdf
```

Notes:
- The script uses the GitHub Search API and is limited to 1,000 results per query.
- Set `GITHUB_TOKEN` to increase API rate limits.
- The PDF is designed for A4 printing.
